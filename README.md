# shomkee.github.io — Shomkee Studio

Личная визитка Шомки: сайты, Telegram-боты и небольшие сервисы.

**Чистая статика. Без сборщика, runtime-зависимостей, CDN, аналитики и внешних API.**

## Запуск

Открой `index.html` или запусти из корня:

```sh
python3 -m http.server 8000
```

Затем открой `http://localhost:8000`. GitHub Pages обслуживает те же файлы без сборки.

## Что внутри

- Адаптивный интерфейс с системной светлой/тёмной темой и ручным переключением.
- RU/EN с сохранением выбора. Старое значение `localStorage.lang` поддерживается.
- Все проекты и контакты есть в HTML и доступны без JavaScript.
- Поиск по проектам и фильтры «Веб / Боты / Desktop».
- Палитра команд: `Ctrl+K` / `⌘K`, стрелки, Enter и Esc. На телефоне — кнопка поиска в шапке.
- Настоящий локальный WebGL: три оригинальные процедурные модели — терминал, робот и орбитальная композиция.
- Вращение мышью, горизонтальным свайпом или стрелками при фокусе на модели. `Home` сбрасывает ракурс.
- Экспорт текущей модели в самостоятельный `.gltf` со встроенной геометрией и цветами. Можно открыть в Blender и совместимых просмотрщиках.
- Автовращение изначально выключено. Его можно включить кнопкой. `prefers-reduced-motion` и режим экономии трафика исключают автоматическое включение; вне экрана и на скрытой вкладке цикл останавливается.
- При отсутствии WebGL показан понятный запасной экран. Остальной сайт работает.
- `localStorage` и буфер обмена защищены обработкой ошибок. Сайт не зависит от их доступности.

## Структура

```text
index.html            Контент, переводы и карточки проектов
css/style.css         Тема, адаптивность, состояния и иллюстрации
js/models.js          Процедурная геометрия и экспорт glTF 2.0
js/scene.js           WebGL-рендерер, ввод и жизненный цикл
js/app.js             Язык, тема, фильтры и палитра команд
assets/favicon.svg   Векторный знак
 tests/models.test.cjs Тесты геометрии и glTF (встроенный Node test runner)
```

Иллюстрации на карточках проектов — стилизованные авторские композиции, **не скриншоты существующих интерфейсов**. Это отмечено и на сайте.

## Редактирование

Проекты находятся в `index.html` внутри `#projects`. У карточки задаются `data-category` и `data-keywords`, у переводимых текстов — `data-ru` и `data-en`. JavaScript не запрашивает список репозиториев и не раскрывает приватные проекты.

Цветовые токены лежат в начале CSS. Светлая и тёмная темы следуют системным предпочтениям, пока посетитель явно не выбрал другую.

Контакт сейчас — публичный профиль GitHub. В исходнике был адрес `no@gmail.com`; он не использован как подтверждённый контакт. Для публичной почты добавь свой адрес в контактный раздел. Приватные данные из других источников сюда не перенесены.

## Проверки

Нужен Node 18+ только для разработки и тестов, не для сайта:

```sh
node --check js/models.js
node --check js/scene.js
node --check js/app.js
node --test tests/models.test.cjs
```

Ручной smoke test: RU/EN, обе темы, три модели, вращение и сброс, glTF-загрузка, автоповорот, поиск с пустой выдачей, все фильтры, палитра команд мышью и клавиатурой, копирование профиля. Повторить на ширине 390 px и с уменьшением движения. Проверить без JavaScript и без WebGL.

## Внедрение

Обновление подготовлено для отдельной ветки. Проверь его до слияния в `main`: в обычной конфигурации GitHub Pages слияние изменит опубликованный сайт. Настройки Pages, домена, доступа и секретов не требуются и этим обновлением не меняются.
