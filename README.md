# shomkee.github.io

Личный сайт-портфолио. Чистая статика: html, css, немного js, без сборки и зависимостей.

Открыть: https://shomkee.github.io

## Структура

```
index.html
css/style.css
js/app.js
```

Проекты лежат массивом в `js/app.js` — чтобы добавить новый, дописать объект туда.
Переключатель RU/EN хранит выбор в localStorage.
